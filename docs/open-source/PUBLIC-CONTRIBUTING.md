# Contributing

For the initial release, issues and design feedback are welcome. External code pull requests are not accepted until a contribution policy and review capacity are published. No DCO or CLA agreement is currently required or accepted by this repository.

Search [existing issues](https://github.com/FanJine-ai/fanjin-community/issues) first. Use synthetic fixtures, zero paid provider calls and no production changes. Keep private data, keys and screenshots of real accounts out of reports. Report vulnerabilities as described in [SECURITY](PUBLIC-SECURITY.md).

Maintainers must preserve third-party notices and upstream author attribution. The repository MIT license does not replace independent licenses of dependencies, fonts, icons or user content.
